# 17A GOAL-MIGRATION-01 Clean Private Repo Bootstrap Through GOAL-06B

## Purpose

Create a clean private repository that becomes the active source of truth for
the project-start-through-GOAL-06B workflow. The legacy repository remains a
historical evidence archive.

## What Project Start Through GOAL-06B Means

The active boundary includes symbol governance, trading calendar, source health,
context contracts, PIT signal snapshot, label construction, feature-label merge,
leakage audit, Stage 6A repair, baseline scoring, and the GOAL-06B supervised
baseline training gate.

The boundary does not include GOAL-06C implementation, ranking baselines,
model comparison, risk overlay, recommendation, dashboard, paper/live trading,
production DB writes, production model promotion, or DQN/RL.

## Capability Catalog Summary

The classified capability catalog is generated at:

`outputs/audits/classified_capability_catalog_through_goal06b.csv`

It separates required active capabilities from legacy evidence, locked
downstream modules, and unclear Class D source-evidence gaps.

## Legacy Exclusion Strategy

The clean repo excludes old step runners, runtime handoff archives, dashboard
and paper-trading code, DQN/RL tests, raw payloads, DBs, notebooks, caches, and
large local artifacts. The concise manifest is:

`outputs/audits/legacy_excluded_from_clean_repo_manifest.csv`

## Compatibility Wrapper Strategy

The public command surface through GOAL-06B remains available under `scripts/`.
Each wrapper delegates to clean active modules and does not import legacy code.

## Diagnostics

Diagnostics are generated by:

`python scripts/run_workflow_diagnostics.py`

The run detail manifest explains the command, stage owner, capability, status,
artifacts, warning, recommendation, owner module, and links to validation and
verification evidence.

## Gates

- Verification: `python scripts/run_e2e_trunk_verification_through_goal06b.py`
- Validation: `python scripts/run_e2e_trunk_validation_through_goal06b.py`
- Regression: `python scripts/run_goal06b_regression_suite.py`
- Safety: `python scripts/run_safety_gate.py`
- Adapter audit: `python scripts/run_adapter_audit.py`

## Remaining Warnings

Known warnings are source coverage limitations and a Class D missing historical
GOAL-05/GOAL-06 docs gap. They do not block Class A reproducibility.

## GOAL-06C

GOAL-06C may start only if the clean bootstrap readiness report explicitly
unlocks it. It must begin as review-only expanded validation and must not unlock
recommendation, risk, dashboard, paper/live trading, production writes, model
promotion, or DQN/RL.
