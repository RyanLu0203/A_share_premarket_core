# Authoritative State Files

The authoritative project state files are:

- `CODEX.md`
- `AGENTS.md`
- `PROJECT_STATE.md`
- `ROADMAP.md`
- `configs/project/workflow_status.csv`
- `docs/governance/GOAL_QUEUE.md`
- `docs/governance/LOCKED_BOUNDARIES.md`
- `docs/governance/GITHUB_ONLY_SOURCE_POLICY.md`
- `docs/governance/WINDOWS_COMPATIBILITY_POLICY.md`
- `docs/governance/CODEX_MAX_REMOTE_WINDOWS_PROTOCOL.md`
- `outputs/audits/current_project_snapshot.md`
- `outputs/audits/current_project_snapshot.json`

Only Main Codex or explicitly assigned governance goals may update these
authoritative state files. Codex Max must not update them unless the assigned
goal explicitly requires the update and Main Codex reviews consistency before
merge.
